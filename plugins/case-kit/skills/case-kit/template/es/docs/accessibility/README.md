## Pruebas manuales
- [ ] Navegación completa con teclado (Tab, Mayús+Tab, Esc y flechas donde aplique)
- [ ] Lector de pantalla: VoiceOver (macOS o iOS) y NVDA si hay acceso a Windows
- [ ] Zoom al 200 % y al 400 % sin pérdida de contenido ni de funciones
- [ ] Reflujo (sin scroll horizontal a 320 px de ancho)
- [ ] `prefers-reduced-motion` respetado
- [ ] Alto contraste y modo oscuro
- [ ] Contraste de color medido (no solo estimado)
